# wafer-space-packaging-debs

> [!WARNING]
> **These packages are not currently usable.** This repository and the
> packages it produces are being generated with AI assistance and are a work
> in progress. Do not rely on them for real designs yet.

Debian and Ubuntu packages (published at `apt.wafer.space`) for the open
source silicon toolchain used by the
[wafer.space GF180MCU project template](https://github.com/wafer-space/gf180mcu-project-template),
built at exactly the same revisions as the template's Nix environment.
